Installer l'imprimante sur un poste

Branchez l'imprimante thermique en USB et lancez Installer_Imprimante_Ticket.cmd (fourni avec EMAB Gestionnaire, menu Démarrer → Installer l'imprimante à tickets). Pour la console locale, le pilote constructeur (Epson Advanced Printer Driver) donne le meilleur rendu des tickets HTML ; il est détecté automatiquement une fois installé.

Le ticket test ci-dessus s'ouvre dans un nouvel onglet et se lance à l'impression : vérifiez la lisibilité, la largeur et la coupe du papier.
